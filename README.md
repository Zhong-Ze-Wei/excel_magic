# Magic Excel

> 让不会写代码的人也能用 AI 处理表格数据。

纯前端 Excel/CSV 智能处理平台。上传表格后在浏览器内完成**数据清洗、智能加工（翻译+打标）、数据摘要**，无需后端，数据不离开浏览器。

## 它能做什么

如果你有一份脏乱的表格（电商评论、问卷反馈、销售流水……），Magic Excel 能帮你：

- **洗干净**：去掉空行、重复、广告、乱码、纯表情等噪声
- **加 AI 列**：批量翻译、情感打标、主题分类、自动给每行生成结构化标签
- **看明白**：AI 通读全表，生成数据概况和关键发现的总结报告

整个过程：上传 → AI 帮你看懂表格 → 选要做的事 → 一键执行 → 导出结果。

## 三大功能模块

### 数据清洗（/cleaning）— 双模式

| 模式 | 适合谁 | 怎么用 |
|------|--------|--------|
| **简易模式** | 不懂规则的小白 | 一句话描述目标（如"删掉水军评论"），AI 自动生成清洗规则，一键出结果 |
| **专家模式** | 要审计的专家 | 手动开关 11 种原子规则 + 8 种自定义筛选，保留/删除/可疑三态审计，可人工覆写 |

- 审计优先：不直接删除，每条规则返回置信度，用户有最终裁决权
- 支持配置 JSON 导入导出（专家模式）

### 智能加工（/process）— 双模式

| 模式 | 适合谁 | 怎么用 |
|------|--------|--------|
| **简易模式** | 想快速出结果 | 选预设模板（翻译中/英/日、情感打标、主题分类），一键跑 |
| **专家模式** | 要精细配置 | 手搓输出列（6 种类型：单选/多选/二级分类/布尔/文本/数值），调参考列和范围，Prompt 双向编译 |

- 翻译已降级为预设模板之一，和打标走同一套「输出列」机制
- 并发逐行打标，实时显示进度
- 打标结果写入全局，可流转到摘要页

### 数据摘要（/summary）

- 列画像引擎：自动检测每列类型（数值/文本/枚举/布尔/日期/标识符），计算分布、高频词、统计指标
- AI 通读全表生成 Markdown 报告（流式输出）
- AI 打标产出的列作为「虚拟列」纳入画像分析
- 可选填分析主题，AI 推荐重点分析列

## 核心特性

- **🧠 AI 意图分析**：上传后 AI 自动读表格快照，推断「你可能想做什么」，给 2-3 个任务目标建议供采纳（可在设置关闭改为手动）
- **🔗 意图上下文贯穿**：任务说明自动作为参考信息注入清洗/加工/摘要的 AI 调用，让每个模块知道「整个数据集要干嘛」
- **🌐 双平台支持**：硅基流动（SiliconCloud）+ aiping.cn，自带 API Key 即可用
- **🔒 纯前端**：无需后端，打开即用，数据不上传任何服务器，Key 仅存本地 localStorage
- **📱 移动端适配**：桌面端侧边栏 + 移动端底部 Tab，双模板完全分离
- **📊 统计图表**：ECharts 环形饼图展示清洗/打标分布
- **📑 多 Sheet 支持**：读取多 Sheet Excel，首页切换

## 快速开始

1. 安装依赖并启动：
   ```bash
   cd app
   npm install
   npm run dev
   ```
2. 浏览器打开提示地址（通常 `http://localhost:5173`）
3. 在设置里配置 API Key（硅基流动或 aiping.cn）
4. 上传表格 → AI 分析意图 → 选任务 → 执行 → 导出
