# Magic Excel

> 让不会写代码的人也能用 AI 处理表格数据。

**快捷入口：** [产品介绍与流程演示](https://zhong-ze-wei.github.io/excel_magic/) · [在线工作台](https://zhong-ze-wei.github.io/excel_magic/app/) · [本地产品页](http://localhost:3323/) · [本地工作台](http://localhost:3322/)

> GitHub Pages 首次发布需在 [仓库 Pages 设置](https://github.com/Zhong-Ze-Wei/excel_magic/settings/pages) 将 Source 设为 **GitHub Actions**，再运行 [部署工作流](https://github.com/Zhong-Ze-Wei/excel_magic/actions/workflows/pages.yml)。本地产品页的启动方法见下方。

纯前端 Excel/CSV 智能处理平台。上传表格后完成**数据清洗、智能加工（翻译+打标）、分组对比、数据摘要**，无需自建后端。文件解析、规则清洗和统计在浏览器内完成；AI 功能会将所选文本与必要上下文发送到你配置的模型服务。

## 它能做什么

如果你有一份脏乱的表格（电商评论、问卷反馈、销售流水……），Magic Excel 能帮你：

- **洗干净**：去掉空行、重复、广告、乱码、纯表情等噪声
- **加 AI 列**：批量翻译、情感打标、主题分类、自动给每行生成结构化标签
- **比较差异**：按产品、渠道或地区分组，对数值求和、求均值或计数，查看图表和明细
- **看明白**：AI 通读全表，生成数据概况和关键发现的总结报告

整个过程：上传 → AI 帮你看懂表格 → 选要做的事 → 一键执行 → 导出结果。

## 四大功能模块

### 数据清洗（/cleaning）— 双模式

| 模式 | 适合谁 | 怎么用 |
|------|--------|--------|
| **简易模式** | 不懂规则的小白 | 一句话描述目标（如"删掉水军评论"），AI 自动生成清洗规则，一键出结果 |
| **专家模式** | 要审计的专家 | 手动开关 10 种原子规则及自定义筛选，保留/删除/待确认三态审计，可人工覆写 |

- 审计优先：不直接删除，每条规则返回置信度，用户有最终裁决权
- 支持配置 JSON 导入导出（专家模式）

### 智能加工（/process）— 双模式

| 模式 | 适合谁 | 怎么用 |
|------|--------|--------|
| **简易模式** | 想快速出结果 | 选预设模板（翻译中/英/日、情感打标、主题分类），一键跑 |
| **专家模式** | 要精细配置 | 手搓输出列（6 种类型：单选/多选/二级分类/布尔/文本/数值），调参考列和范围，Prompt 双向编译 |

- 翻译已降级为预设模板之一，和打标走同一套「输出列」机制
- 并发逐行打标，实时显示进度
- 打标结果写入全局，可流转到摘要页

### 分组对比（/aggregate）

- 按一列分组，对另一列做 SUM / AVG / COUNT / MIN / MAX
- 同时展示柱状图与分组明细，可导出结果
- 例如：按产品比较评分均值，按渠道比较点赞总数
- 空评分不作为零分参与均值

### 数据摘要（/summary）

- 列画像引擎：自动检测每列类型（数值/文本/枚举/布尔/日期/标识符），计算分布、高频词、统计指标
- AI 通读全表生成 Markdown 报告（流式输出）
- AI 打标产出的列作为「虚拟列」纳入画像分析
- 可选填分析主题，AI 推荐重点分析列

## 核心特性

- **🧠 AI 意图分析**：上传后 AI 自动读表格快照，推断「你可能想做什么」，给 2-3 个任务目标建议供采纳（可在设置关闭改为手动）
- **🔗 意图上下文贯穿**：任务说明自动作为参考信息注入清洗/加工/摘要的 AI 调用，让每个模块知道「整个数据集要干嘛」
- **🌐 双平台支持**：硅基流动（SiliconCloud）+ aiping.cn，自带 API Key 即可用
- **🔒 纯前端**：无需自建后端，本地读表与规则统计；AI 按需请求模型服务，Key 保存在本地 localStorage
- **📱 移动端适配**：桌面端侧边栏 + 移动端底部 Tab，双模板完全分离
- **📊 统计图表**：ECharts 环形饼图展示清洗/打标分布
- **📑 多 Sheet 支持**：读取多 Sheet Excel，首页切换

## 快速开始

1. 安装依赖并启动：
   ```bash
   cd app
   npm install
   npm run dev
   ```
2. 浏览器打开提示地址（默认 `http://localhost:3322`）
3. 在设置里配置 API Key（硅基流动或 aiping.cn）
4. 上传表格 → AI 分析意图 → 选任务 → 执行 → 导出

也可以先加载 **32 行 × 8 列的模拟电商评论**。默认核心列为“评论内容”，无密钥时可体验专家规则清洗、列画像与分组对比。

### 产品说明页与静态演示

产品页提供真实界面截图、五步流程演示、截图放大和示例 CSV 下载。演示使用预设标签与摘要，无需 API Key，也不会发送 AI 请求。

在仓库根目录执行：

```bash
npm --prefix app run build:pages
node scripts/build-pages.mjs
node scripts/preview-pages.mjs
```

打开 [本地产品页](http://localhost:3323/)，从页面可直接进入同一构建产物里的工作台。静态页面维护和 GitHub Pages 发布说明见 [site/README.md](site/README.md)。
