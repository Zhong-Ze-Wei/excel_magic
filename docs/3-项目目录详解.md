# 项目目录详解

## 顶层目录

```
magic-excel/
├── app/                    # 主应用目录 (Vue 3 SPA)
├── data/                   # 示例数据文件
├── docs/                   # 项目文档
├── Translation & Analysis Tool.html    # v1 版本 (单文件 HTML 原型)
└── Translation_Analysis_Tool_v2.html   # v2 版本 (单文件 HTML 原型)
```

### `Translation & Analysis Tool.html`
- **作用**：v1 版本的单文件 HTML 原型
- **说明**：早期原型，所有 HTML/CSS/JS 写在一个文件中，功能较简单

### `Translation_Analysis_Tool_v2.html`
- **作用**：v2 版本的单文件 HTML 原型
- **说明**：在 v1 基础上增加了更多功能，是当前 Vue 版本的前身。当前版本的大部分逻辑（AI 调用、Prompt 模板、清洗规则）都是从这个文件迁移而来

### `data/`
- **作用**：存放示例数据文件
- **内容**：
  - `conir Target 英文待翻译.xlsx` — 翻译任务原始英文数据
  - `conir Target 英文待翻译_腾讯MT7B已翻译.xlsx` — 腾讯 MT7B 模型翻译结果
  - `Kenra_Reviews_Fixed.xlsx` — Kenra 品牌评论数据
  - `28868448_重采-vivoX300系列月报数据-0205_XT_20260209_171034.csv` — vivo 手机月报数据

## `app/` — 主应用

### 构建配置文件

#### `app/package.json`
- **作用**：项目依赖和脚本配置
- **关键依赖**：
  - `vue` ^3.5.13 — 核心框架
  - `vue-router` ^4.5.0 — 路由
  - `pinia` ^2.3.0 — 状态管理
  - `xlsx` ^0.18.5 — SheetJS，Excel 读写
  - `lucide-vue-next` ^0.468.0 — 图标库
- **开发依赖**：
  - `vite` ^6.0.0 — 构建工具
  - `@vitejs/plugin-vue` ^5.2.0 — Vite Vue 插件
  - `tailwindcss` ^3.4.17 — CSS 框架
  - `postcss` / `autoprefixer` — CSS 后处理
- **脚本**：
  - `npm run dev` — 启动开发服务器
  - `npm run build` — 生产构建
  - `npm run preview` — 预览生产构建

#### `app/vite.config.js`
- **作用**：Vite 构建配置
- **内容**：配置 Vue 插件

#### `app/tailwind.config.js`
- **作用**：Tailwind CSS 配置
- **内容**：扫描路径、主题扩展

#### `app/postcss.config.js`
- **作用**：PostCSS 配置
- **内容**：加载 Tailwind CSS 和 Autrefixer 插件

#### `app/index.html`
- **作用**：HTML 入口文件
- **内容**：挂载 `#app` div，引入 `/src/main.js`

### `app/src/` — 源代码

#### `app/src/main.js`
- **作用**：应用入口
- **职责**：
  1. 创建 Vue 应用实例
  2. 安装 Pinia 插件
  3. 安装 Vue Router 插件
  4. 引入全局样式
  5. 挂载到 `#app`

#### `app/src/App.vue`
- **作用**：根组件
- **职责**：
  1. 定义整体布局：左侧 Sidebar + 右侧主内容区
  2. 主内容区包含 Header + router-view（带 fade 过渡动画）
  3. 全局挂载 SettingsModal（通过 Teleport 渲染到 body）
- **结构**：
  ```
  <div class="flex h-screen">
    <Sidebar />
    <main>
      <Header />
      <router-view /> (带 transition 动画)
    </main>
    <SettingsModal />
  </div>
  ```

#### `app/src/styles/main.css`
- **作用**：全局样式
- **内容**：Tailwind 指令引入、自定义全局样式（滚动条、动画等）

### `app/src/config/` — 配置常量

#### `app/src/config/defaultSettings.js`
- **作用**：默认配置常量定义
- **导出**：
  - `DEFAULT_API_PLATFORMS` — API 平台配置
    - `siliconflow`：硅基流动平台（URL、注册链接、Key 获取链接、邀请码、翻译模型列表、分析模型列表）
    - `aiping`：aiping.cn 平台（同上结构）
  - `DEFAULT_RULES_CONFIG` — 数据清洗默认规则配置
    - 各规则的 enable 状态、参数默认值
    - 无意义短词库默认值
    - 广告引流敏感词库默认值
    - 弱规则策略默认值（mark）

### `app/src/router/` — 路由

### `app/src/stores/` — Pinia 状态管理

#### `app/src/stores/data.js`
- **作用**：基础数据存储
- **职责**：简单的 headers/rows/fileName 容器
- **方法**：`setData()` / `clear()`
- **说明**：这个 store 目前使用较少，大部分场景用 dataShare 替代

#### `app/src/stores/dataShare.js`
- **作用**：全局数据共享总线（核心 store）
- **职责**：
  1. 存储全局 Excel 数据（headers, rows, sourceName）
  2. 管理全局核心处理列索引（coreColumn）
  3. 启发式推荐核心列
  4. 数据在模块间流转
- **关键属性**：
  - `headers` — 全局表头数组
  - `rows` — 全局数据行二维数组
  - `sourceName` — 数据来源名称
  - `coreColumn` — 核心处理列索引（默认 0）
  - `hasData` — 是否有数据（computed）
- **关键方法**：
  - `setSharedData(headers, rows, name, autoDetect)` — 存入数据
  - `setCoreColumn(idx)` — 设置核心列
  - `getAndClearSharedData()` — 取出并清空
  - `clearSharedData()` — 清空
  - `heuristicDetectCoreColumn()` — 启发式推荐（平均文本长度最长）

#### `app/src/stores/settings.js`
- **作用**：API 配置与清洗规则设置中心
- **职责**：
  1. 管理当前 API 平台选择
  2. 管理各平台 API Key
  3. 管理各平台翻译/分析模型选择
  4. 管理数据清洗规则配置（深度 watch 自动持久化到 localStorage）
  5. 配置导入/导出/重置
- **持久化 Key**：
  - `api_platform` — 当前平台
  - `{platform}_api_key` — 各平台 API Key
  - `{platform}_translate_model` — 各平台翻译模型
  - `{platform}_work_model` — 各平台分析模型
  - `magic_excel_cleaning_rules` — 清洗规则配置 JSON
- **关键方法**：
  - `getApiConfig()` — 获取完整 API 调用配置对象
  - `exportGlobalConfig()` — 导出全局配置 JSON 文件
  - `importGlobalConfig(parsed)` — 导入配置
  - `resetAllConfig()` — 恢复出厂设置

### `app/src/services/` — 核心业务服务

#### `app/src/services/ai.js`
- **作用**：AI API 调用封装
- **导出函数**：
  - `callAI(content, systemPrompt, modelOverride)` — 非流式调用
  - `callStreamingAI(systemPrompt, userPrompt, onChunk, modelOverride)` — 流式调用
  - `testConnection(platform, key)` — 测试 API 连通性
- **调用格式**：OpenAI 兼容（Bearer Token + messages 数组）

#### `app/src/services/excel.js`
- **作用**：Excel/CSV 文件读写
- **导出函数**：
  - `readFile(file)` — 读取文件，返回 `{ headers, rows }`
  - `exportToXlsx(headers, rows, filename, sheetName)` — 导出 xlsx
- **导出常量**：
  - `DEMO_DATA` — 内置示例数据（产品参数 + 用户评论）

#### `app/src/services/prompts.js`
- **作用**：所有 AI Prompt 模板集中管理
- **导出常量**：
  - `TRANSLATE_SCENARIOS` — 翻译场景选项
  - `LANGUAGE_DIRECTIONS` — 语言方向选项
- **导出函数**：
  - `getTranslatePrompt(scenario, direction)` — 翻译 Prompt
  - `getAnalysisPrompt(categories)` — 分析 Prompt（旧版兼容）
  - `getAnalysisSystemPrompt(taxonomy)` — 分析 System Prompt
  - `getColumnDetectionPrompt(headers, sampleRows)` — AI 列推荐 Prompt
  - `getTagGenerationPrompt(samples, taxonomyGoal)` — AI 标签生成 Prompt
  - `getPromptOptimizerPrompt(goal, taxonomy)` — AI Prompt 优化
  - `getFormulaPrompt()` — 公式生成 Prompt
  - `getSmartFilterPrompt(...)` — AI 智能筛选 Prompt

#### `app/src/services/cleaningRules.js`
- **作用**：数据清洗规则引擎
- **导出函数**：
  - `normalizeText(text)` — 文本标准化
  - `checkIsEmpty(text)` — 空文本检测
  - `checkTooShort(text, minLength)` — 字数过短检测
  - `checkDuplicate(text, index, textFreq, firstIndices, minCount)` — 精确去重
  - `checkPureEmoji(text)` — 纯表情检测
  - `checkPureSymbol(text)` — 纯标点检测
  - `checkLinkOnly(text)` — 纯链接检测
  - `checkTopicOnly(text, ratioThreshold)` — 纯话题检测
  - `checkShortMeaningless(text, phrases)` — 短无意义词检测
  - `checkAdLinkPattern(text, keywords)` — 引流广告检测
  - `checkGarbledText(text, threshold)` — 乱码检测
  - `evaluateCustomFilter(filter, row, normText, sourceColIdx)` — 自定义规则评估
  - `runCleaningPipeline(rows, headers, sourceColIdx, rulesConfig)` — Pipeline 主控

### `app/src/views/` — 页面视图

#### `app/src/views/HomeView.vue`
- **作用**：功能主页
- **功能**：全局 Excel 上传、工作表信息展示、核心列选择、6 个功能卡片导航
- **依赖**：dataShare store、FileUploader 组件、excel 服务

#### `app/src/views/CleaningView.vue`
- **作用**：数据清洗页面
- **功能**：10 种规则开关配置、自定义筛选规则、AI 智能筛选、审计表格、决策覆写、导出、共享
- **依赖**：dataShare store、settings store、cleaningRules 服务、ai 服务、prompts 服务、CustomFilterForm 组件
- **代码行数**：~940 行（最复杂的视图）

#### `app/src/views/TranslateView.vue`
- **作用**：批量翻译页面
- **功能**：翻译配置、逐行 AI 翻译、进度展示、导出结果
- **依赖**：dataShare store、ai 服务、excel 服务、prompts 服务、DataTable 组件、ProgressOverlay 组件

#### `app/src/views/AnalysisView.vue`
- **作用**：评论分析页面
- **功能**：评论列选择（AI 推荐）、分类体系管理（AI 生成）、分析范围、逐行 AI 分析、情感统计、导出
- **依赖**：dataShare store、settings store、ai 服务、prompts 服务、FileUploader 组件
- **代码行数**：~820 行

#### `app/src/views/SummaryView.vue`
- **作用**：数据摘要页面
- **功能**：数据概览、列统计、AI 流式生成分析报告
- **依赖**：dataShare store、ai 服务（流式）、FileUploader 组件

#### `app/src/views/TextTranslateView.vue`
- **作用**：文本翻译页面
- **功能**：左右双栏输入/输出、一键翻译、复制译文
- **依赖**：ai 服务、prompts 服务

#### `app/src/views/FormulaView.vue`
- **作用**：公式生成页面
- **功能**：自然语言输入、AI 生成公式 + 说明
- **依赖**：ai 服务、prompts 服务

### `app/src/components/` — 组件

#### `app/src/components/common/FileUploader.vue`
- **作用**：文件上传组件
- **Props**：`label`, `icon`, `iconBg`, `iconColor`
- **Events**：`@file` — 返回 File 对象
- **功能**：点击上传、拖拽上传、格式限制 (.xlsx/.xls/.csv)

#### `app/src/components/common/DataTable.vue`
- **作用**：数据表格组件
- **Props**：`title`, `headers`, `rows`, `maxRows`, `emptyText`, `heightClass`, `rowCount`
- **Slots**：`actions`（右上角操作区）、`overlay`（表格覆盖层）
- **功能**：表头展示、数据行展示、空状态、最大行数限制

#### `app/src/components/common/ProgressOverlay.vue`
- **作用**：进度遮罩层组件
- **Props**：`visible`, `current`, `total`, `text`
- **功能**：百分比进度条 + 文字提示

#### `app/src/components/layout/Sidebar.vue`
- **作用**：左侧导航栏
- **功能**：Logo 展示、功能分组导航（Excel 处理 / AI 助手）、API 设置入口
- **路由高亮**：根据当前路由路径高亮对应导航项

#### `app/src/components/layout/Header.vue`
- **作用**：顶部标题栏
- **功能**：显示当前页面标题、当前模型名称、GitHub 链接

#### `app/src/components/settings/SettingsModal.vue`
- **作用**：全局设置弹窗
- **功能**：
  - Tab 1：API 平台选择、API Key 输入、模型选择、测试连接、注册福利
  - Tab 2：弱规则策略、各清洗规则参数配置
  - 底部：导入/导出配置、重置默认、保存
- **技术**：使用 Teleport 渲染到 body

#### `app/src/components/cleaning/CustomFilterForm.vue`
- **作用**：自定义筛选规则编辑弹窗
- **Props**：`filter`（编辑时传入，新建时为 null）、`headers`
- **Events**：`@save`、`@cancel`
- **功能**：8 种规则类型的动态表单、正则校验、关键词/列值输入
