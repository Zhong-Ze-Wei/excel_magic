# PRD — Magic Excel 智能数据分析助手

## 1. 产品概述

### 1.1 产品定位
Magic Excel 是一款面向电商运营、数据分析师、内容审核人员的**纯前端 Excel 智能处理工具**。通过集成大语言模型能力，将传统需要数小时人工完成的数据清洗、翻译、分析工作压缩到分钟级。

### 1.2 目标用户
- **电商运营**：需要批量翻译产品参数、分析用户评论、清洗社媒数据
- **数据分析师**：需要快速了解新数据集的特征、清洗脏数据
- **内容审核人员**：需要从海量评论中过滤广告、乱码、无意义内容
- **普通办公用户**：需要 AI 辅助生成 Excel 公式

### 1.3 核心价值
- **效率提升**：AI 驱动的批量处理，替代重复性人工操作
- **数据质量**：10 种内置规则 + AI 智能筛选，系统化保障数据质量
- **一站式流程**：数据在清洗、翻译、分析模块间无缝流转，无需重复上传
- **数据安全**：纯前端架构，用户数据不离开浏览器

---

## 2. 功能需求

### 2.1 全局数据管理

#### 2.1.1 全局数据上传
- **入口**：首页功能主页
- **支持格式**：.xlsx, .xls, .csv
- **交互方式**：点击上传、拖拽上传
- **上传后行为**：
  - 数据存入全局共享总线
  - 自动启发式推荐核心处理列（平均文本长度最长的列）
  - 所有子模块自动读取全局数据

#### 2.1.2 核心处理列
- 用户可手动切换核心处理列
- 核心列被数据清洗、批量翻译、评论分析模块共享
- 列切换时各模块自动同步

#### 2.1.3 数据流转
- 清洗模块可将清洗后的数据写回全局总线
- 翻译/分析模块可读取清洗后的数据继续处理
- 支持"共享结果至..."一键跳转

---

### 2.2 数据清洗模块

#### 2.2.1 内置原子规则（10 种）

| 规则 | 类型 | 说明 | 默认参数 |
|------|------|------|----------|
| 文本标准化 | 预处理 | 去控制字符、压缩空白、去首尾空格 | 始终开启 |
| 空文本过滤 | 强删 | 标准化后为空的文本 | 开启 |
| 字数过短 | 强删 | 有效字符数 < 阈值 | 开启, 阈值=2 |
| 精确去重 | 强删 | 重复次数 >= 阈值，保留首条 | 开启, 阈值=3 |
| 纯表情过滤 | 强删 | 纯 Emoji 或 [xxx] 占位表情 | 开启 |
| 纯标点过滤 | 强删 | 去空格后无中英文数字 | 开启 |
| 纯链接过滤 | 强删 | 纯 HTTP/HTTPS 网址 | 开启 |
| 纯话题过滤 | 强删 | 话题标签占比 > 阈值 | 开启, 阈值=0.8 |
| 短无意义词 | 强删 | 匹配水贴词库 | 开启 |
| 引流广告 | 弱规则 | 引流词 + 链接组合 | 开启 |
| 疑似乱码 | 弱规则 | 非常规字符占比 > 阈值 | 开启, 阈值=0.4 |

#### 2.2.2 弱规则策略
- **标记待确认**（默认）：命中弱规则的行标记为 suspect，需人工确认
- **直接强删**：命中弱规则的行直接标记为 delete

#### 2.2.3 自定义筛选规则
- 支持 8 种规则类型：
  - 文本包含/不包含关键词
  - 文本精确匹配
  - 正则匹配
  - 文本长度筛选
  - 列值精确匹配
  - 数值列大于/小于
- 每条规则可设置：名称、类型、作用列、命中策略（删除/待确认）
- 支持手动添加、编辑、删除

#### 2.2.4 AI 智能筛选
- 用户用自然语言描述筛选意图（如"过滤掉负面评论"）
- AI 分析全表结构，找到最相关的列
- 自动生成精确的列级匹配规则或文本匹配规则
- 自动应用到清洗配置

#### 2.2.5 审计与覆写
- 审计表格显示前 100 行数据
- 每行显示：状态标签、命中规则、置信度、原文、标准化文本
- 用户可逐行覆写决策（强制保留 / 强制删除）
- 统计面板实时更新（保留数、删除数、待确认数）

#### 2.2.6 导出
- **导出保留数据**：仅导出 keep 状态的行
- **导出审计报表**：导出全量数据 + 标准化文本 + 决策状态 + 命中原因

#### 2.2.7 配置管理
- 清洗规则配置自动持久化到 localStorage
- 支持导入/导出配置 JSON
- 支持恢复出厂设置

---

### 2.3 批量翻译模块

#### 2.3.1 翻译配置
- **源列选择**：选择需要翻译的列（默认使用全局核心列）
- **翻译场景**：
  - 产品参数（准确/术语）
  - 用户评论（情感/口语）
  - 竞品标题（SEO 优化）
  - 邮件沟通（正式商务）
  - 通用翻译
- **语言方向**：
  - 自动检测 → 中文
  - 中文 → 英文
  - 英文 → 中文
  - 中文 → 日文

#### 2.3.2 翻译执行
- 逐行调用 AI 翻译
- 实时显示进度（已处理行数 / 总行数）
- 翻译结果实时写入表格新列
- 翻译过程中数据同步回全局总线

#### 2.3.3 结果导出
- 导出包含翻译结果列的完整 xlsx

---

### 2.4 评论分析模块

#### 2.4.1 分析配置
- **评论列选择**：手动选择或 AI 推荐
- **分析范围**：指定开始行和结束行
- **分类体系**：双层树状标签（一级大类 > 二级子标签）

#### 2.4.2 分类体系管理
- 手动添加/删除一级分类和二级子标签
- AI 智能生成：根据样本评论自动提炼分类体系
- 支持模糊生成目标（如"侧重售后与包装"）

#### 2.4.3 分析执行
- 逐行调用 AI 分析
- 返回结果：情感倾向 (Positive/Negative/Neutral) + 分类路径
- 实时显示进度和当前处理行
- 统计面板：正面/负面/中性占比

#### 2.4.4 高级设置
- **模糊分析目标**：用户描述分析重点，AI 优化 Prompt
- **System Prompt 定制**：可手动修改或 AI 优化
- **AI 推荐列**：自动识别评论内容列

#### 2.4.5 结果导出
- 导出包含情感倾向列和分类标签列的完整 xlsx

---

### 2.5 数据摘要模块

#### 2.5.1 数据概览
- 列数、行数
- 每列非空行数
- 数据平均非空率

#### 2.5.2 AI 摘要生成
- 流式输出分析报告
- 内容包括：数据概述、统计特征、业务洞察
- Markdown 格式渲染

---

### 2.6 文本翻译模块

#### 2.6.1 功能
- 左右双栏：原文输入 / 译文输出
- 通用翻译场景，自动检测源语言 → 中文
- 一键翻译，支持复制译文

---

### 2.7 公式生成模块

#### 2.7.1 功能
- 自然语言描述需求
- AI 生成 Excel 公式 + 使用说明
- 公式代码高亮显示，支持一键复制

## 3. 系统设置

### 3.1 API 配置
- **支持平台**：
  - 硅基流动 (SiliconFlow) — SiliconCloud 平台
  - aiping.cn — AI 聚合开放平台
- **配置项**：
  - API Key（密码输入框，支持显示/隐藏）
  - 翻译专用模型（下拉选择或自定义输入）
  - 常规分析模型（下拉选择或自定义输入）
- **辅助功能**：
  - 测试连接按钮
  - 注册福利横幅（含邀请码）
  - 平台切换

### 3.2 清洗规则配置
- 弱规则全局策略（标记/强删）
- 各规则开关和参数调节
- 无意义短词库编辑
- 广告引流敏感词库编辑
- 乱码判定阈值调节

### 3.3 配置备份
- 导出全局配置 JSON（API Key + 模型选择 + 清洗规则）
- 导入配置 JSON
- 恢复出厂设置（二次确认）

## 4. 非功能需求

### 4.1 性能
- 文件上传后即时解析，无延迟
- 清洗 Pipeline 对前 100 行实时预览，全表统计异步计算
- 流式输出场景实时渲染，不阻塞 UI

### 4.2 兼容性
- 现代浏览器（Chrome, Edge, Firefox, Safari）
- Excel 2007+ 格式 (.xlsx)、旧格式 (.xls)、CSV 全支持
- 中文编码兼容（codepage: 936）

### 4.3 数据安全
- 纯前端架构，Excel 数据不上传到任何服务器
- 仅 AI 处理的文本片段发送到第三方 API
- API Key 存储在 localStorage，用户可随时清除

### 4.4 可用性
- 响应式布局，支持桌面端
- 操作反馈：进度条、loading 状态、toast 提示
- 错误处理：API 调用失败、文件解析失败、JSON 解析失败均有友好提示

---

## 5. 技术约束

- 纯前端 SPA，无后端服务
- AI 能力依赖第三方 OpenAI 兼容 API
- localStorage 存储限制（约 5-10MB）
- 大文件处理受限于浏览器内存
