# 产品说明

## 产品定位

Magic Excel 是一个纯前端的 Excel/CSV 智能处理平台。用户上传 Excel 文件后，在浏览器内完成数据清洗、翻译、AI 打标、数据摘要等操作，无需安装任何软件，无需后端服务。

核心价值：**让不会写代码的人也能用 AI 处理表格数据。**

## 用户前提

- 用户自行提供 AI API Key（硅基流动或 aiping.cn 平台）
- 数据在浏览器内处理，不上传到任何服务器
- 支持 xlsx、xls、csv 格式

## 功能模块

### 1. 数据清洗（CleaningView）

**解决的问题**：用户有一列文本数据（如评论、反馈），里面混杂着空行、重复内容、纯表情、乱码、广告引流等脏数据，需要清洗后再分析。

**核心交互**：
1. 上传 Excel 或从首页关联数据
2. 选择清洗目标列（默认推荐核心列）
3. 左侧面板配置规则开关和参数
4. 点击"执行清洗"，系统逐行判定每行的 keep/delete/suspect 状态
5. 右侧结果表用颜色标注（绿=保留，红=待删，黄=可疑），用户可逐行覆写
6. 确认后导出清洗结果

**规则体系**：
- **强删规则**（默认开启）：空文本、过短、精确重复、纯链接、纯表情、纯符号、纯话题标签、短无意义词
- **弱规则**（可选策略）：疑似广告引流、疑似乱码。策略分两种：标记为待确认（默认），或直接强删
- **自定义规则**：用户通过弹窗配置 8 种自定义匹配规则（关键词包含/不包含、精确匹配、正则、文本长度、列精确匹配、列数值比较）
- **AI 智能筛选**：用户用自然语言描述筛选意图，AI 自动分析全表结构，找到最相关的列，生成精确的匹配规则

**关键设计**：审计优先，不直接删除。每条规则返回置信度，用户有最终裁决权。

### 2. 批量翻译（TranslateView）

**解决的问题**：用户有一列外语文本（产品参数、评论、标题等），需要批量翻译成目标语言。

**核心交互**：
1. 上传 Excel 或从首页关联数据
2. 选择翻译源列、翻译场景（产品参数/用户评论/竞品标题/邮件/通用）、语言方向（自动→中/中→英/英→中/中→日）
3. 点击"开始批量翻译"，系统并发调用 AI 逐行翻译
4. 结果追加到表格末尾的"翻译结果"列
5. 导出翻译结果

**翻译场景**：
- 产品参数：保留技术术语（mAh、IP68）和数字
- 用户评论：保留原始情感，口语化
- 竞品标题：保留型号/品牌，优化搜索
- 邮件：正式商务语气
- 通用：准确翻译，无额外处理

**特殊机制**：翻译缓存，相同文本不重复调用 AI。翻译过程中如遇 API 限流（429），自动降低并发数。

### 3. AI 表格打标（AnalysisView）

**解决的问题**：用户有一张数据表，想用 AI 为每行新增若干分析列（如情感倾向、问题分类、是否需要退货等），不想手动逐行标注。

**核心交互**：
1. 上传 Excel 或从首页关联数据
2. 选择 AI 参考列（多选，告诉 AI 分析时看哪些列）
3. 用自然语言描述需求（如"帮我新增情感倾向、主要问题类型、是否有退换货意愿、证据短句四列"）
4. 点击"AI 生成打标方案"，AI 返回结构化的 outputColumns 方案
5. 用户可查看/编辑/新增/删除输出列，可展开"高级 Prompt 预览"查看编译后的 system prompt
6. 点击"开始 AI 打标"，系统并发逐行调用 AI，实时显示进度
7. 结果直接显示在表格右侧的 AI 新增列中
8. 导出打标结果（原始列 + AI 新增列合并导出）

**6 种输出列类型**：
- **enum**（单选标签）：从固定选项中选择一个，如情感: 正面/负面/中性
- **multi_enum**（多选标签）：从固定选项中选择多个，如问题类型: [质量, 物流]
- **hierarchical_enum**（二级分类）：一级 > 二级路径，如 质量 > 破损
- **boolean**（是否判断）：true/false/null
- **text**（自由文本）：摘要、证据短句
- **number**（数值评分）：数字或 null

**关键设计**：
- Prompt 双向编译：AI 生成方案 → 编译成 system prompt；用户手动编辑 prompt → 反向解析回方案
- JSON 容错解析：AI 返回的 JSON 经常包裹在 markdown 代码块中或前后有多余文字，统一走 `parseRobustJSON` 处理
- 结果规范化：AI 返回的 enum 值如果不在 options 里，自动回退到第一个选项
- 打标结果写入全局 `dataShare.labelingResults`，供数据摘要页使用

### 4. AI 数据摘要（SummaryView）

**解决的问题**：用户有一张大表，想快速了解数据的整体特征、分布、异常，不想逐列手动统计。

**核心交互**：
1. 上传 Excel 或从首页关联数据
2. 可选：输入分析主题（如"客户满意度"、"产品质量"），点击"AI 推荐分析列"自动选择重点列和分析角度
3. 可手动选择要分析的列（多选 checkbox，默认全选）
4. 点击"开始生成数据摘要"，系统先预计算列画像，再调用流式 AI 生成报告
5. 右侧实时显示 Markdown 格式的分析报告（标题、列表、表格等完整排版）

**列画像引擎**：
- 自动检测列类型（数值/文本/枚举/布尔/日期/标识符）
- 数值列：min/max/mean/median/stddev/分位分布
- 枚举列：值分布（Top 15 值的占比）
- 文本列：长度统计、高频词（简单标点分词，2-8 字片段）
- 日期列：时间范围
- 交叉统计：按维度列分组，计算指标列的均值或值分布

**AI 打标结果回接**：如果用户先在"AI 表格打标"页执行了分析，摘要页会自动将打标结果的每个 outputColumn 作为"虚拟列"纳入画像，让 AI 报告覆盖打标结果的分布。

**AI 报告结构**：数据集概览 → 列级洞察 → 数据分布特征 → 交叉分析发现 → 数据质量评估 → 业务建议。

## 跨模块串联流程

典型的多步处理流程：

```
上传 Excel（首页）
  → 数据清洗（去除脏数据、广告、乱码）
  → 批量翻译（如有外语文本列）
  → AI 打标（新增情感/分类/评分列）
  → 数据摘要（生成全表分析报告）
  → 导出最终结果
```

每步完成后数据可写回 dataShare，下一步自动读取。用户也可以跳过某些步骤，或在任意步骤单独上传文件处理。

## API 配置

用户需要在设置弹窗中配置：
- **平台选择**：硅基流动（SiliconCloud）或 aiping.cn
- **API Key**：从对应平台获取
- **翻译模型**：每个平台提供 3-5 个模型可选
- **分析模型**：每个平台提供 3-5 个模型可选
- **并发数**：批量调用时的最大并发数（默认 20，上限 100），遇 API 限流自动降级
- **配置管理**：支持导入/导出/重置全部配置（JSON 文件）
