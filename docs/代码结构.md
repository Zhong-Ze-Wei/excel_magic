# 代码结构

基于 commit `78e76ee`，master 分支（重构后）。

## 入口

| 文件 | 作用 |
|------|------|
| `main.js` | Vue 应用入口，注册 Pinia 和 Router |
| `App.vue` | 条件渲染入口：`useDevice()` 判断设备，桌面端 → DesktopLayout，移动端 → MobileLayout；根级挂载 ImportIntentModal（全局单例） |

## 路由

| 路径 | 页面 | 功能 |
|------|------|------|
| `/` | HomeView | 功能主页，上传入口，数据集意图卡，3 大功能卡片 |
| `/cleaning` | **CleaningHub** | 清洗统一入口，按 `settings.cleaningMode` 切换简易/专家模式 |
| `/process` | AnalysisHub | 智能加工（翻译+打标），双模式：简易 AnalysisSimpleView / 专家 AnalysisView，共享 dataShare.labelingPlan |
| `/summary` | SummaryView | AI 数据摘要，列画像引擎 + 流式报告 |
| `/translate` | — | 重定向到 `/process`（过渡期，计划随 TranslateView 删除） |
| `/analysis` | — | 重定向到 `/process`（过渡期） |
| `/optimize` | — | 重定向到 `/cleaning`（过渡期） |

## Stores

| 文件 | 作用 |
|------|------|
| `stores/dataShare.js` | 全局数据总线。存 headers/rows/sourceName/coreColumn/labelingResults，新增 translatedColumns（翻译列元信息）、sheetNames/currentSheet/file（多 Sheet）。子模块通过 `useGlobalDataSync` composable 自动同步。`setSharedData(newHeaders, newRows, name, autoDetect, options)` 第 5 参数接收 sheet 元信息；autoDetect 已失效（意图驱动替代）。Actions: setCoreColumn / addTranslatedColumn / setSheet（懒加载切 Sheet）/ setLabelingResults |
| `stores/importIntent.js` | **新增**。上传后意图状态：coreColumnIdx（核心列）、tasks（clean/process/summary 多选）、note（任务说明，最多 500 字）。ImportIntentModal 写入，HomeView 和各功能页读取 |
| `stores/settings.js` | API 配置中心 + AI 行为开关。管理当前平台、API Key、翻译/分析模型、并发数、rulesConfig（清洗规则，UI 入口已统一到专家模式 CleaningRulesPanel）、`dataInsightMode`（洞察引擎）、`autoIntentAnalysis`（导入后是否自动 AI 分析意图，默认开）。`cleaningMode`（simple/expert）控制 CleaningHub 切换；`processMode`（simple/expert）控制 AnalysisHub 切换。全部持久化到 localStorage |

## Services

| 文件 | 作用 |
|------|------|
| `services/ai.js` | AI 调用封装。`callAI` 非流式（temperature=0.3, max_tokens=2048），`callStreamingAI` 流式 SSE（temperature=0.7, max_tokens=4096），`callAIBatch` 批量并发（信号量控制，默认 20，上限 100，429 自动降级），`testConnection` 测试连通性 |
| `services/cleaningRules.js` | 清洗引擎。11 种原子规则 + `evaluateCustomFilter`（8 种自定义规则）+ `runCleaningPipeline` 汇总决策。OptimizeView 和 CleaningView 共用 |
| `services/dataProfiler.js` | 列画像引擎。`detectColumnType`、`computeColumnProfile`、`computeAllProfiles`、`computeCrossTabs`、`stratifiedSample`、`formatProfilesForAI`。重构后精简（-73 行） |
| `services/excel.js` | SheetJS 封装。`readFile` 读取（含多 Sheet 元信息）、`readSheet` 懒加载单 Sheet、`exportToXlsx` 导出，内置 DEMO_DATA |
| `services/jsonParser.js` | JSON 容错解析。`parseRobustJSON` 剥离 markdown 围栏，提取最外层括号 |
| `services/prompts.js` | Prompt 模板中心。重构后 +79 行，新增翻译预设模板等 prompt。`formatIntentContext(note, stepFocus)` 把数据集意图格式化为「参考段」供各模块 system prompt 追加（ADR 0008） |
| `services/intentAnalysis.js` | **新增**。导入后 AI 意图分析。`buildTableSnapshot`（列画像+分层抽样）、`analyzeTableIntent`（调 AI 返回 2-3 个任务方案建议）、`normalizeSuggestions`（字段名/索引/置信度校验兜底） |
| `services/toast.js` | 全局通知。`useToast()` 替代 `alert()` |
| `services/translationCache.js` | 翻译缓存。`createTranslationCache()` 内存 Map |

## Composables

| 文件 | 作用 |
|------|------|
| `composables/useDevice.js` | 设备检测，返回 `{ isMobile, isDesktop }` |
| `composables/useGlobalDataSync.js` | 全局数据同步，封装 onMounted + watch(rows.length) + importGlobalExcel |
| `composables/useFileUpload.js` | 文件上传 + 自动弹 ImportIntentModal + 错误处理 |
| `composables/useExport.js` | 导出逻辑封装 |
| `composables/useCleaningPipeline.js` | 清洗管道（预览+全量统计+导出），OptimizeView/CleaningView 共用 |
| `composables/useLabeling.js` | **新增**。打标编排（批量调 AI + 进度管理 + 结果回写 dataShare），AnalysisSimpleView/AnalysisView 共用 |
| `composables/useShare.js` | 数据共享 + 路由跳转 |
