# 代码结构

基于 commit `c2e932f`，master 分支。

## 入口

| 文件 | 作用 |
|------|------|
| `main.js` | Vue 应用入口，注册 Pinia 和 Router |
| `App.vue` | 根布局：左侧 Sidebar + 右侧主区域（Header + router-view + 路由切换动画），全局挂载 SettingsModal 和 ToastContainer |

## 路由

| 路径 | 页面 | 功能 |
|------|------|------|
| `/` | HomeView | 功能主页，上传全局 Excel 入口，展示关联状态和表头预览 |
| `/cleaning` | CleaningView | 数据清洗，11 种原子规则 + 自定义规则 + AI 智能筛选 |
| `/translate` | TranslateView | 批量翻译，整列翻译，支持 5 种场景 + 4 种语言方向 |
| `/text` | TextTranslateView | 文本翻译，左右分栏的自由文本翻译，单次调用 |
| `/analysis` | AnalysisView | AI 表格打标，自然语言生成打标方案，逐行并发打标 |
| `/summary` | SummaryView | AI 数据摘要，列画像引擎 + 交叉分析，流式生成 Markdown 报告 |
| `/formula` | FormulaView | 公式生成，自然语言描述需求，返回 Excel 公式 + 使用说明 |

## Stores

| 文件 | 作用 |
|------|------|
| `stores/dataShare.js` | 全局数据总线。存 headers/rows/sourceName/coreColumn/labelingResults，所有子模块通过 onMounted 自动读取。`setSharedData` 支持 `autoDetect` 启发式推荐核心列（取前 15 行中平均文本长度最长的列） |
| `stores/settings.js` | API 配置中心。管理当前平台、API Key、翻译/分析模型选择、并发数、清洗规则配置。全部持久化到 localStorage。支持配置导入/导出/重置 |

## Services

| 文件 | 作用 |
|------|------|
| `services/ai.js` | AI 调用封装。`callAI` 非流式（temperature=0.3, max_tokens=2048），`callStreamingAI` 流式 SSE（temperature=0.7, max_tokens=4096），`callAIBatch` 批量并发调用（信号量控制，429 自动降级并发数），`testConnection` 测试 API 连通性 |
| `services/cleaningRules.js` | 清洗引擎。11 种原子规则（空文本、过短、重复、纯表情、纯符号、纯链接、纯话题、短无意义词、广告引流、乱码），每条返回 `{ hit, reason, confidence }`。`evaluateCustomFilter` 处理 8 种自定义规则类型（textContains/textNotContains/textEquals/regexMatch/textLength/columnEquals/columnGt/columnLt）。`runCleaningPipeline` 汇总所有规则，输出每行的 keep/delete/suspect 决策 |
| `services/dataProfiler.js` | 列画像引擎。`detectColumnType` 自动检测列类型（boolean>number>date>identifier>enum>text），`computeColumnProfile` 计算单列统计（数值列: min/max/mean/median/stddev/分位分布，枚举列: 值分布，文本列: 长度统计/高频词，日期列: 时间范围），`computeCrossTabs` 交叉统计，`stratifiedSample` 头/中/尾分层抽样，`formatProfilesForAI` 格式化为 AI 可读文本 |
| `services/excel.js` | SheetJS 封装。`readFile` 读取 xlsx/xls/csv（自动补齐每行长度与表头对齐），`exportToXlsx` 导出，内置 `DEMO_DATA`（comments/specs 两套示例数据） |
| `services/jsonParser.js` | JSON 容错解析。`parseRobustJSON` 剥离 markdown 代码围栏，提取最外层 `{}` 或 `[]`，容错 `JSON.parse`，失败返回 null |
| `services/prompts.js` | Prompt 模板中心。翻译相关：`getTranslatePrompt`（5 种场景 × 4 种方向）。打标相关：`getLabelingPlanGenerationPrompt`（自然语言→打标方案）、`compileLabelingPrompt`（方案→system prompt）、`getPlanFromPromptPrompt`（prompt→反向解析回方案）。摘要相关：`getDataSummaryPrompt`（列画像→分析报告）。其他：`getColumnDetectionPrompt`、`getFormulaPrompt`、`getSmartFilterPrompt`，以及已废弃的 `getAnalysisSystemPrompt`、`getTagGenerationPrompt`、`getPromptOptimizerPrompt` |
| `services/toast.js` | 全局通知。`useToast()` 返回 `{ show, success, error, info, warn, dismiss, clearAll }`，替代全项目的 `alert()` |
| `services/translationCache.js` | 翻译缓存。`createTranslationCache()` 返回内存 Map 缓存，`get/set/has/clear/stats`，跳过已翻译文本避免重复调用 AI |

## Components

| 文件 | 作用 |
|------|------|
| `components/common/FileUploader.vue` | 通用文件上传，点击 + 拖拽，支持 xlsx/xls/csv |
| `components/common/DataTable.vue` | 通用数据表格，支持自定义 header 和行渲染 slot |
| `components/common/ProgressOverlay.vue` | 进度遮罩层，显示当前/总数和百分比 |
| `components/common/ToastContainer.vue` | Toast 通知容器，固定在右下角，自动消失 |
| `components/layout/Sidebar.vue` | 左侧导航栏，分"Excel 处理"和"AI 助手"两组，底部 API 设置按钮带连接状态指示灯 |
| `components/layout/Header.vue` | 顶部栏 |
| `components/settings/SettingsModal.vue` | 全局设置弹窗（Teleport to body），平台切换、API Key 配置、模型选择、并发数、配置导入导出重置 |
| `components/cleaning/CustomFilterForm.vue` | 清洗模块的自定义规则编辑弹窗，支持 8 种规则类型 |

## Config

| 文件 | 作用 |
|------|------|
| `config/defaultSettings.js` | 导出 `DEFAULT_API_PLATFORMS`（硅基流动 + aiping.cn 两个平台的 URL、模型列表、注册链接）和 `DEFAULT_RULES_CONFIG`（清洗规则默认开关和参数） |
