# 数据管道

## 核心数据流（重构后：意图驱动）

重构后核心变化：上传不再做启发式列检测，改为弹 `ImportIntentModal` 让用户明确「核心列 + 任务」。数据流从「自动检测」转向「意图驱动」。

```

│ HomeView │ ─────────────────────────────→ │ dataShare store │
│ 上传 Excel│  setSharedData(headers,rows,  │ + importIntent  │
└──────────┘   name, false, {sheets...})    └────────┬────────┘
               ↓ 弹 ImportIntentModal                 │
┌─────────────────────┐  intent.submit()              │
│ ImportIntentModal   │ ─→ importIntent store          │
│ 核心列+任务+说明     │ ─→ dataShare.setCoreColumn()   │
└─────────────────────┘                                │
                                                       │
        ┌──────────────────────────────────────────────┤
        ▼                       ▼                      ▼
┌──────────────┐       ┌──────────────┐       ┌──────────────┐
│ CleaningHub  │       │ AnalysisView │       │ SummaryView  │
│ /cleaning    │       │ /process     │       │ /summary     │
│              │       │ (智能加工)    │       │ (摘要)        │
│ 简易/专家切换 │       │ 翻译+打标    │       │              │
└──────┬───────┘       └──────┬───────┘       └──────┬───────┘
```

## dataShare store 状态（重构后）

```js
{
  headers: string[],
  rows: any[][],
  sourceName: string,
  coreColumn: number,          // 由 ImportIntentModal 设置，非启发式
  labelingResults: {           // 打标结果（翻译列也并入此结构）
    outputColumns: Array,
    analysisMap: { [rowIdx]: { values: {...} } }
  } | null,
  translatedColumns: [         // 新增：翻译列元信息
    { originalIdx, translatedIdx, name }
  ],
  sheetNames: string[],        // 新增：多 Sheet
  currentSheet: string,
  file: File                   // 新增：原始文件引用，供 setSheet 懒加载
}
```

## 意图驱动流程（替代旧启发式检测）

1. **上传**：`useFileUpload.handleFile()` 调 `readFile` → `setSharedData(..., false, {sheetNames, currentSheet, file})` → 自动 `intent.open()`
2. **收集意图**：ImportIntentModal 让用户选
   - 核心处理列（必填，下拉单选）
   - 任务多选（clean / process / summary）
   - 任务说明（可选，≤500 字，作 AI 上下文）
3. **提交**：`intent.submit()` → `dataShare.setCoreColumn(idx)` + `dataShare.setIntentNote(note)` → 弹窗关闭
4. **跳转**：HomeView 根据选中的 tasks 显示快捷入口按钮，用户点击跳转

**注意**：`setSharedData` 的 `autoDetect` 参数保留但已失效（不再做启发式判断）。核心列完全由用户在 IntentModal 指定。

### 意图上下文的分层注入（ADR 0008）

任务说明（`dataShare.intentNote`）以**参考段**形式注入三个功能区的 AI 调用，**不覆盖各模块自己的目标字段**（userGoal / theme 等），让 AI 区分「数据集整体任务（宏观）」与「本步骤聚焦（微观）」。

统一 helper：`formatIntentContext(note, stepFocus)` → 返回
```
【数据集整体任务（参考）】{note}
本步骤请聚焦：{stepFocus}。
```
（note 为空时返回空串，对无意图场景零影响）

| 模块 | 注入位置 | stepFocus | 自己的目标字段（保留不动） |
|------|---------|-----------|----------------------|
| 智能加工 | 方案生成 system prompt | 为表格新增列 | `userGoal`（页面内可改） |
| 清洗（简易） | 方案生成 system prompt | 数据清洗 | system prompt 基础角色 |
| 摘要 | 总结 system prompt | 数据摘要与洞察 | `analysisTheme` |

详见 `docs/adr/0008-意图上下文分层注入.md`。

## 各模块的数据读写行为

### Composables 数据流抽象层

| Composable | 职责 |
|-----------|------|
| `useGlobalDataSync` | onMounted + watch(rows.length) 自动同步全局数据到本地 |
| `useFileUpload` | readFile + setSharedData + 弹 IntentModal + 错误处理 |
| `useExport` | 封装 exportToXlsx 调用 |
| `useShare` | setSharedData 写回 + 路由跳转 |

### HomeView（上传入口 + 意图分发）

- **写入**：上传后 setSharedData（autoDetect 失效），弹 IntentModal 收集意图
- **读取**：dataShare.sourceName / rows.length / coreColumn，importIntent.tasks
- **展示**：数据集意图卡 + 3 大功能卡片（清洗/加工/摘要）

### CleaningHub（清洗统一入口）

- **角色**：容器 + 模式切换宿主，按 `settings.cleaningMode`（simple/expert）渲染 OptimizeView 或 CleaningView
- **共享数据**：两个子视图都从 dataShare 读全局数据，无 props 传递
- **简易模式（OptimizeView）**：AI 跑完后直接写入 `settings.rulesConfig`，与专家模式共享同一份规则；suspect 降级为 delete（仅展示层）；`settings.lastAiConfigAt` 标记是否跑过 AI（会话内有效）
- **专家模式（CleaningView）**：读写 `settings.rulesConfig` 持久化，保留 keep/delete/suspect 三态审计 + 人工覆写
- **模式切换**：因 `aiRulesConfig` 是 computed from settings.rulesConfig，用户在专家模式调整规则后切回简易模式立即反映
- **写回**：通过 useShare.applyToGlobal() 写回 dataShare

### AnalysisView（智能加工 = 翻译 + 打标）

- **读取**：useGlobalDataSync 同步；importIntent.note 作 AI 上下文
- **翻译已降级为预设模板**：PRESET_TEMPLATES 里包含翻译模板，走打标流程产出「翻译列」
- **写入**：`setLabelingResults(outputColumns, analysisMap)` + `addTranslatedColumn(originalIdx, translatedIdx, name)` 记录翻译列元信息
- **不修改** headers/rows，打标/翻译结果独立存储在 labelingResults

### SummaryView（数据摘要）

- **读取**：useGlobalDataSync 同步 headers/rows
- **读取 labelingResults**：每个 outputColumn（含翻译列）作为「虚拟列」纳入画像
- **不写入** dataShare

## 多 Sheet 支持

- 上传时 `readFile` 返回 sheetNames，存入 dataShare
- `setSheet(sheetName)` 懒加载：动态 import excel.js 的 readSheet，只解析目标 Sheet
- HomeView 有 Sheet 选择器，切换时调 `dataShare.setSheet()`

## 核心列（coreColumn）机制（重构后）

**旧逻辑（已废弃）**：启发式取前 15 行平均文本长度最长的列。

**新逻辑**：完全由用户在 ImportIntentModal 显式选择。`setCoreColumn(idx)` 可独立调用（不必随 setSharedData）。

## AI 调用模式

| 模式 | 函数 | 使用场景 | 特点 |
|------|------|----------|------|
| 非流式 | `callAI` | 打标、方案生成 | temperature=0.3, max_tokens=2048 |
| 流式 | `callStreamingAI` | 数据摘要报告 | temperature=0.7, max_tokens=4096, SSE |
| 批量并发 | `callAIBatch` | 打标整表、翻译整列 | 信号量控制，默认 20，上限 100，429 自动降级 |

所有 AI 调用从前端直接发 HTTP 请求到第三方 API，API Key 从 settings store 读取。
